# Security policy

## Supported versions

Only the latest 1.x release of SignalDesk receives fixes.

## Reporting a vulnerability

Please report vulnerabilities privately. Open the Security tab of this repository and choose "Report a vulnerability". Include the version, steps to reproduce and the impact you expect. Please do not open a public issue for a security problem. Reports are acknowledged as soon as possible.

## Scope

The hosted demo runs entirely in your browser with sample data and sends nothing to a server. If you run the server yourself, put it behind your own authentication and network controls. The "Design notes and limitations" section of the README lists what the server does not protect.
