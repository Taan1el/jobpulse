# Product Roadmap

This note keeps SignalDesk's product direction close to the codebase so future changes stay focused.

## Current Product Focus

- Keep the app frontend-first with local persistence.
- Maintain a clear reference matrix for reusable dashboard, API, and delivery patterns.
- Keep REST-style UI states visible without adding unnecessary backend complexity.
- Preserve strong tests, responsive polish, GitHub Actions checks, screenshots, and concise setup docs.

## Improvement Backlog

1. Capture fresh screenshots after visual changes.
2. Extract repeated controls into a small component library once patterns stabilize.
3. Add optional import/export schema validation for safer JSON handoff.
4. Let users rename or delete individual signals and tasks.
