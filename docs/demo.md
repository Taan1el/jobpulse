# JobPulse Demo

JobPulse is designed to show practical frontend skills against real frontend/full-stack listing requirements.

## What To Notice

- The target-listing matrix connects project work to specific job requirements.
- The integration-readiness panel shows loading, ready, empty, and error states without requiring a backend.
- The requirement signal list supports filtering, local persistence, and JSON export.
- The build queue makes the next project improvement visible.
- Tests and GitHub Actions cover the core dashboard workflow.
